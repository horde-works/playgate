# Совместная визуальная правка

Цель этого файла: **следующий крупный тип** (A-380 и любой другой) не
должен требовать сотни скриншотов «видишь щель?». Хозяин — последняя
приёмка, не детектор. Каждая поправка в сессии DC-3 17–19.08.2026
(транскрипт `1fcbb7a9-2664-4145-afcc-5e360718031d`) — это проверка, которую
агент обязан сделать **сам**, до показа.

Предметный итог той сессии — [`dc-3/runtime-lessons.md`](dc-3/runtime-lessons.md).
Камера Object Lab — [`run-and-verify.md`](run-and-verify.md) и
`reference-faithful-object-study/references/verification-visual-loop.md`.
Скиллы сюда ссылаются и не пересказывают.

---

## 0. Память агента — не чат

После автокомпакта веса **не помнят** сессию. Cursor кладёт JSONL в
`agent-transcripts/<uuid>.jsonl` и после сжатия пишет путь в системное
сообщение. Summary — чужой слой: законы и файлы, не «что хозяин запретил».

Если спросили «как мы это делали» — искать реплику в транскрипте. Не
подменять практику предметным каноном.

## 1. Хозяин не ловит за агента

Кадр хозяина — гейт. Он не заменяет ортогональ Object Lab, вид из кресла,
оба борта и замер по референсу. Если ждать, пока хозяин пришлёт «видишь?»,
на A-380 это снова будет сотня шагов.

Перед показом агент сам:

1. Снимает / смотрит те же ракурсы, с которых потом будут судить (профиль,
   3/4, сверху, из кресла, с хвоста, оба борта).
2. Сверяет с референсом и **пишет, что видит**, ещё до правки. «Что ты
   видишь?» в той сессии было не вежливостью — агент шёл кодить, не
   посмотрев.
3. Называет одну меняемую часть и что заморожено.
4. Прогоняет чеклист §2. Показ хозяину — после него, не вместо.

Хозяин сам сомневается в ракурсе. Тогда измерить, а не кивнуть. Вординг
агента, который расходится с кадром, — стоп: «зашить над дверью» звучало
локально, на кадре не дотягивала **ширина фюзеляжа**.

## 2. Чеклист до показа (чтобы не ловить это скриншотом)

Снято с повторяющихся возвратов той сессии. Новый тип проходит тот же
список, даже если хозяин молчит.

**Форма**

- Направление верное ≠ тип времени ≠ наша форма. Не копировать референс
  на чужой обвод: вписать в доступный угол, скос и масштаб **этой** машины.
- Слова хозяина — гипотеза. «Колпак = продолжение кабины» ломает принятое.
  Тянуть только новую деталь.
- Не нашлепка: править большой элемент. Dummy-объёмы на плите, заплатки
  под окном, третье стекло «для дырки» — шаг назад.
- Не «осторожно, чтобы не сломать»: это недокрут. Либо число с референса,
  либо названные миллиметры.
- Законцовка крыла — целое; элерон/руль — врезка, их не скруглять и не
  тянуть до тип. Ядро не торчит сквозь обшивку.
- Накладка носа: не переписывать принятое тело, чтобы скруглить кончик.
- Стык — **внешние** грани, которые видит глаз, не внутренние полки рам.
- Левое и правое, верх и низ — четыре места, не одно. «Зашил над левой и
  под правой» оставляет дыры наоборот. Не верить симметрии правки.
- `left`/`right` в id — знак оси, не борт типа. Капитан DC-3 на порту (+X),
  id `…-right`. На новой машине сначала `forward × up`, потом имена.

**Проёмы**

- Сначала накладка на кожу (форма, место, скругление). Потом вырез.
  Потом обвод ядра, чтобы прутья не стояли в проходе.
- Цвет накладки = цвет корпуса, пока судят силуэт, не краску.
- Вырез в шкуре — тот же контур, что створка. Гермообвод описывает проём,
  не «почти».

**Интерьер и занятие**

- Судить из глаз сидящего, не стоя на кресле. Капсула ≠ камера
  (`runtime-lessons` §2).
- Не переворачивать штурвал и приборы из-за местных осей плиты.
- Не перестраивать общий `MotionInstrumentSystem` под одну машину.
- Sit/stand бьют соседнюю дверь: радиус вызова и `preferredEntryInteraction`.
- Меню: ход рейса, не `flight !== null`. Створки в рейсе — члены кластера,
  не кинематика вдогонку (`runtime-lessons` §§4–5).

**Посадка в мир**

- «Невидимая стена» — спросить, **какое тело** встретило грунт
  (`runtime-lessons` §7). Не хоронить стойку ради AABB.
- Лететь стабильно ниже ленты — не «в допуске». Править тот участок
  маршрута, который врёт.

**Дисциплина**

- Один шаг. Дыры — в конце, если не сказано иначе.
- Коммит-чекпоинт до выреза / до рискованного лофта.
- Принятое и соседа не рестайлить. Явный список файлов.
- `compileScene` / висящие куски — стоп.
- Вердикт хозяина в том же проходе становится тестом (класс, не экземпляр).
- Параллель на вторую машину — только по просьбе.

## 3. Слон по частям

Не делать «всю кабину». Два лобовых → боковое → обвод → дыры.

Автономия бывает («я отъехал — доведи»). Это не разрешение объявить
готовым без тех ракурсов, с которых будут судить. На A-380 автономный
кусок всё равно заканчивается чеклистом §2, не «я думаю, вышло».

---

## 4. Три согласия и откат

1. Направление. 2. Тип / время. 3. Адаптация к нашей форме.

Не каждый промах — «верни». Бывает **«пока не откатывай, адаптируй»**
(стёкла не влезли в наш лоб — вписать, не копировать оригинал). Откат —
когда сломали уже принятое или пошли за метафорой.

Откатывать **этот шаг**. Не дерево, не Kallur, не `git add -A`.
«Именно там верни как было» — соседний обвод, задетый заодно.

Ранняя реплика «сосед только экспериментирует, можно захватить в коммит»
не отменяет `shared-tree-discipline.md`, когда соседняя линия (Kallur)
живая. Слушать **текущую** инструкцию про этот коммит.

---

## 5. Соседняя машина, не новая петля

Кресло, горизонт, plug-slide, lock створок в рейсе — уже есть. Сначала
найти живой механизм. Распашная «как у оригинала» запрещена, если в мире
принят сдвиг. Новый тип садится на тот же контракт, не на свой
`inFlight`.

---

## 6. Коммит, сосед, не копать

- «Принимаем / фиксируем» → коммит явным списком, потом `git log -1` /
  `git status`. «А коммит сделан?» в той сессии был не ритуалом.
- После своего коммита чужую правку (развесовка, шасси в грунте) смотреть
  **отдельной** задачей, не смешивать с формой.
- Первый поворот руления промахнулся, остальные верны — не копать, пока
  это не очевидный закон. На A-380 то же: не разбирать весь маршрут из-за
  одного кадра, если остальное держит коридор.

## 7. Типовые ошибки сессии DC-3 → что сделать самому

| если не проверить | получится снова |
|---|---|
| Метафора хозяина как чертёж | сломанная принятая кабина |
| Референс на нашу форму один в один | стёкла не в обводе |
| Скруглить элерон с законцовкой | гармошка / тонкий тип |
| Переписать всю накладку ради кончика | потерянный принятый нос |
| Утопить стойку ради тангажа | снаружи одни шины |
| Сесть на `…-left` | вид с кресла штурмана |
| Нашлепки над плитой | «панель» в стекле |
| `flight !== null` | меню как в воздухе на стоянке |
| Кинематика створки за корпусом | дёрганье в рейсе |
| Зашить одну сторону | дыры зеркально |
| Стык внутренних граней рам | щель, которую видит глаз |
| Сразу вырезать дверь | дыры в шкуре без принятой формы |
| Лететь ниже ленты «в допуске» | весь маршрут под глиссадой |
| Вспышка на грязи = невидимая стена | нос клюёт, «чинят» ILS |
| Не открыть транскрипт после компакта | записать канон вместо приёма |

## 8. Петля шага (агент крутит сам)

1. Референс + текущий кадр. Написать, что видно.
2. Одна часть; заморозка названа.
3. Шаг. Чеклист §2 по задетым бортам и стыкам.
4. Куда смотреть хозяину (кресло, бетон у носа, хвост, оба борта) — уже
   проверено агентом.
5. «Не туда» → откат шага или адаптация, как сказано, без спора.
6. Коммит — по «принимаем», явным списком, проверка что он в дереве.
