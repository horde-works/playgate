# Douglas DC-3 — исследование объекта

Документальный объект для Playgate. Строится в Object Lab, в мир **не
поставлен**: ни префаба, ни адаптера, ни физики до явной приёмки формы.

Канонический владелец геометрии —
`games/make-a-mess/src/content/objects/vehicles/dc3Object.ts`.
Кадры снимаются `scripts/capture-dc3-object-lab.mjs` через репозиторный
рендерер; каждый кадр несёт ревизию и хэш модели.

## Порядок работы

Строить дальше только после словесного вердикта владельца по кадрам. Каждый
принятый вердикт в том же проходе становится **именованным тестом**, а не
записью в журнале.
