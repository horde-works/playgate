# Zaan yard kit — research renders

These PNGs are design references, not canonical Object Lab captures.
They isolate each prop from the world and show one consistent proposal from
multiple fixed angles before canonical geometry is authored.

## Milestone 1

- `01-schouw-multi-angle.png` — accepted 4.60 × 1.45 m shallow-water workboat;
  it owns the visible silhouette and character. Published construction and the
  passport own hidden topology and exact dimensions.
- `02-mooring-posts-multi-angle.png` — two 1.60 m tarred oak piles at 3.20 m
  centres with four-faced caps and forged rings.
- `03-jetty-multi-angle.png` — 2.40 × 1.10 m private landing stage, four piles,
  seven deck boards and two water steps, without rails.

## Milestone 2 baseline

- `04-yard-shed-multi-angle.png` — 4.60 × 6.40 m tarred Zaan yard shed with a
  brick plinth, red clay-tile roof, white double cargo doors, one six-pane side
  window and the projecting hoist beam as the defining joint.

The final implementation must be recaptured through the repository Object Lab
so every fixed view shares the canonical model revision and hash.

The dimensional and construction contract for these three objects is recorded
in `evidence-card-01-03.md` before canonical geometry is revised.
