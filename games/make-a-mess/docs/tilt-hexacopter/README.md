# Tilt hexacopter object study

This directory contains the first canonical 3D engineering blockout derived from
the owner-approved generated concept. The concept controls visible character and
topology; hidden geometry and dimensions are explicitly authored hypotheses.

- `reference/approved-concept.png`: frozen owner-approved source image.
- `evidence-card-01-tilt-hexacopter.md`: claim ledger and acceptance limits.
