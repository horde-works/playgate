# SR-6 «Скат» — индекс объекта

Прототип шестироторной машины с туннельными вентиляторами рыскания. Стоит на
северном лугу города как выставочный берт (`sr6Skat.ts`, `sr6SkatObject.ts`);
публичного рейса пока нет — геометрия, урон, актуация и лётная динамика живые.

## Принятое состояние

- **Приёмочная запись — [`evidence-card-m10.md`](evidence-card-m10.md)**:
  инварианты, измеренные станции, бюджет деталей, rejection conditions.
- **Рендеры принятой ревизии — [`m9/`](m9/)**: 13 видов + `manifest.json`,
  model hash `c890322475bc`, сняты с той же code-native модели, чьи станции
  зафиксированы в evidence-card-m10.
- **Концепт — [`reference/`](reference/)**: `concept-direction.png` — выбранное
  владельцем ImageGen-направление (Tier E: только характер и материалы, НЕ
  источник размеров; лист самопротиворечив — верх-правая проекция рисует четыре
  канала на шестиканальной машине, план снят с ¾-вида);
  `reference-selected.png` — пользовательский кроп выбора.

## История ревизий

M1 (отвергнутая архитектура 3+3) → M2–M3 (принятое направление 4+2, выбор
владельца записан) → M4 (силовые элементы убраны из ометаемых зон) → M5–M6 →
M7–M9 (авторский инструментарий, коробчатая пространственная ферма, гранёная
капсула выживания; уроки подняты в casebook скилла
reference-faithful-object-study) → **M10 — принято**.

Папки промежуточных ревизий m1–m6 и по-milestone README удалены 2026-08-06 по
конвенции скилла (канонические записи — evidence card + discrepancy log +
единый индекс объекта); их содержимое доступно в git-истории до этой даты.
